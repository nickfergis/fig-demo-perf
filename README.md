# FIG demos (public)

Public demo pages for the FIG (Fix-It Group) meetings, served by GitHub Pages.

- `/` : **HoldCo Demo**, the Operations Performance Platform demo (synthetic company data on real
  2025-2026 weather for Denver, Phoenix and Dallas). Single self-contained page.
- `/training/` : **Training Platform Demo**, the interactive platform diagram; click a DEMO box to play
  its recorded demo (PMD, LMS and AI training videos, live AI coach).

Sources and build scripts for the HoldCo demo live in the private MyTeams repo
(`multi-tenant/nick/engagements/fig/demo/`). Track: FIG_DEMO_PERF (MT-175).
